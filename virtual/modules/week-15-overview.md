## What students usually struggle with
- If the rationale was not started during Week 14 beta review, the final version usually becomes generic. Expand the draft you already started instead of writing from scratch now.
- Last-minute code changes are risky if you do not re-test keyboard flow, loading states, and the production build afterward.
