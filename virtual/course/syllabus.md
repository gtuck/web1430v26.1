## Learning outcomes

- Build responsive, standards-based pages with semantic HTML5 and modern CSS.
- Write readable JavaScript that uses variables, control flow, functions, arrays, objects, and modules.
- Use browser developer tools to inspect, debug, and improve client-side code.
- Manipulate the DOM to create interactive interfaces that respond to user events.
- Design and validate accessible forms that provide clear feedback and error recovery.
- Exchange data with external services using JSON and the Fetch API.
- Persist client-side state with local storage and session storage when appropriate.
- Apply introductory component-based thinking with a modern JavaScript framework.
- Collaborate with Git and GitHub using a documented, reproducible workflow.
- Plan, build, test, and present a polished client-side web project.

## Attendance and participation

Live sessions are where concepts are introduced, demos are run, and lab work is scaffolded — treat them like face-to-face class meetings. Expectations:

- Attend both weekly sessions; join on time with a working microphone. Camera use is encouraged but not required.
- If you must miss a session, watch the recording before the next session and follow up in office hours with questions — recordings are a recovery tool, not a substitute for regular attendance.
- Participation includes responding to in-session checkpoint questions, sharing your screen during lab debugging when asked, and contributing to code review discussions.
- Repeated unexplained absences will be treated the same way as non-participation in any Weber State course; contact the instructor early if circumstances interfere with attendance.

## Session recordings

Class sessions are recorded and posted to Canvas for review and for students who miss a session. Recordings are available only to enrolled students, are not to be redistributed, and may capture student audio, video, and shared screens. If you have concerns about being recorded, contact the instructor during the first week.

## Lecture delivery

The week's core concepts are taught live in the Monday session, with the Wednesday session dedicated to applying them. The written lecture notes in Canvas cover the same material as the live sessions — code examples, a demo walkthrough, and a practice prompt — and serve as your reference after class and your catch-up path if you miss a session. Lecture notes are designed to be read alongside the corresponding textbook chapter: the chapter provides conceptual grounding and the notes provide worked examples and common mistakes. Attending the sessions and doing the reading are both expected; neither alone is sufficient.

## Exams

**Midterm Exam** — administered at the end of Week 8. Covers Weeks 01–07 (browser fundamentals, HTML/CSS, JavaScript syntax, control flow, data modeling, DOM, events, and forms). Format: multiple-choice and true/false questions in Canvas, timed at 60 minutes. Open notes, closed collaboration. The Week 8 sessions include a structured midterm review.

**Final Exam** — administered during Week 15. Cumulative, covering Weeks 01–14. Weighted toward the second half of the course (Weeks 09–14: async/Fetch, storage, modules, Vue). Format: multiple-choice and true/false questions in Canvas, timed at 90 minutes. Open notes, closed collaboration. The Final Exam counts for approximately two-thirds of the 15% exam credit; the Midterm counts for one-third.

Both exams are taken in Canvas within the exam window rather than during a live session. They are designed to confirm understanding of concepts introduced in class sessions and textbook chapters, and complement — but do not replace — the applied skills demonstrated in labs, assignments, and projects.

## Accessibility and inclusion

Course materials are designed for keyboard access, meaningful headings, readable contrast, and clear instructions. Live sessions use Zoom features that support access (captions, chat-based participation, posted recordings). Students are encouraged to use accommodations and communicate early.

## Academic standards

Students are expected to submit original work, credit borrowed assets appropriately, and document AI-assisted work when used for brainstorming, debugging, or drafting.

## Tech stack

HTML5, CSS3, JavaScript, JSON, Fetch API, localStorage/sessionStorage, ES modules, Vite, Vue (introductory), Git, GitHub, browser developer tools, and Zoom for live sessions.
