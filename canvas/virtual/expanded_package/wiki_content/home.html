WEB 1430: Client-Side Web Development

Welcome to the virtual section of WEB 1430: Client-Side Web Development, built for the Weber State University School of Computing Web/UX pathway. This section meets live over Zoom — Monday and Wednesday, 9:30–10:45 AM (Mountain Time) — with all course materials, submissions, and assessments in Canvas.

Course promise

By the end of the term, you will be able to plan, build, debug, test, and present polished client-side web experiences using semantic HTML, modern CSS, JavaScript, browser APIs, and an introductory JavaScript framework.

Course map

  • Start Here module
  • 15 weekly learning modules, each anchored by two live class sessions
  • Original course textbook with 14 chapters
  • Labs, quizzes, assignments, two major projects, and a final project
  • Midterm and final exam
  • Published support guides for accessibility, APIs, screen reader testing, and the Vue transition
  • Mid-course and late-course check-ins to monitor pacing and support needs
  • GitHub-based workflow and Canvas delivery
  • Lightweight project documentation and deployed QA expectations throughout the course

Major tools

  • Zoom (live class sessions)
  • Canvas LMS
  • VS Code
  • Chrome DevTools
  • Git + GitHub
  • Vite
  • Vue (introductory level)

First steps

  1. Read the syllabus, including the class meeting schedule and attendance expectations
  2. Test your Zoom setup (audio, screen sharing) and bookmark the class meeting room link from the syllabus
  3. Attend the first live session on Monday, August 24 at 9:30 AM
  4. Complete the Start Here module and clone or create your course repository
  5. Set up your local development environment and verify git status / git pull --ff-only
  6. Submit the orientation quiz and welcome survey
  7. Read the Accessibility Fundamentals Primer before Week 2
