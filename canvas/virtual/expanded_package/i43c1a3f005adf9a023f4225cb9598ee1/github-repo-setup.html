GitHub Repo Setup – Course Repository and First Push

Due: End of Week 0
Points: 10
Category: Orientation

Purpose

Every lab, assignment, and project in this course is submitted through GitHub. This assignment confirms your repository, local toolchain, and sync habits work before Lab 01, so setup problems never collide with a content deadline.

What to do

  1. Follow the Week 00 lecture and Lab 00 handout to request your course repository through the course repo request page and clone it to your machine:
  2. Don't have a GitHub account? Create one first at https://github.com/join using your @mail.weber.edu email address — you'll use the same username in the next step.
  3. Go to https://crsapps.netlify.app/gh?instructor=gt&course=WEB1430&task=CourseTemplate
  4. Enter your GitHub username exactly as it appears on GitHub (typos will block submission).
  5. Enter the course passcode — it is posted in the Course Repo Passcode announcement in Canvas (Announcements → Course Repo Passcode).
  6. Click Create Repo. You'll get an invitation link — accept it, and your repository (with the course starter files already in it) is ready to clone from the web1430-fall26 organization.
  7. Make at least one meaningful commit locally — for example, add your name and a short course goal to README.md — with a clear commit message, and push it to GitHub.
  8. Verify your sync habits from the terminal:
  • git status reports a clean working tree
  • git pull --ff-only completes without errors
  1. Confirm your pushed commit is visible on your repository page on GitHub.

What to submit

  • URL: your course repository's GitHub URL.
  • Text entry: one or two sentences stating what git status and git pull --ff-only told you when you ran them.

Grading

Credit is based on a working setup: the repository exists, contains at least one meaningful pushed commit authored by you, and your submission shows you ran the sync checks. If any step fails, bring it to office hours or the Help & Questions board this week — resolving it now is the entire point of the assignment.
