Final Project Revised Wireframe and Data Plan – Milestone 2

Due: End of Week 13
Points: 20
Category: Projects (Milestone 2 of 5)

Purpose

Milestone 2 of the Final Project is revision, not invention. You already have a starter sketch and a draft normalized object from Milestone 1. Use Week 13 to revise them now that you have scaffolded the project or proven one core interaction is technically possible.

If you are still inventing the whole project this week, narrow the scope immediately and say so in your submission — that is useful information, and it is recoverable in Week 13. It is not recoverable in Week 15.

What to submit

In projects/final-project/:

  • wireframes/ — at least three sketches: the initial/empty state, the loaded state, and a detail or interaction state. Photographs of hand-drawn sketches are fine.
  • data-plan.md — covering the shape of one normalized data object (all properties, types, sources); what is stored in localStorage (key name, value shape, when it is written and read); which UI states exist (loading, empty, error, success, detail); and where each major piece of state lives.

Use fictional or demo data while planning. Do not store passwords, government IDs, tokens, or other sensitive personal data in Web Storage.

Submit to Canvas: your repository URL, plus a direct link to data-plan.md in the text entry.

How this is graded

  • Three-plus wireframes and a complete data plan, visibly revised from Milestone 1 (20)
  • Complete, but essentially unchanged from the Milestone 1 starter (15) — the revision is the point
  • Wireframes or data plan present, not both (12)
  • One sketch and a sentence (6)
  • Not submitted (0)
