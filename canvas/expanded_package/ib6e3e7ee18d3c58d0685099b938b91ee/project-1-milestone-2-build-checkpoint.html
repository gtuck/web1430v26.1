Project 1 Build – Milestone 2

Due: End of Week 7
Points: 25
Category: Projects (Milestone 2 of 3)

Purpose

A deployed, in-progress version of Project 1 – Interactive Style Guide. The point of this checkpoint is to catch deployment problems and scope problems while there is still a week left to fix them — not to have a finished project.

What to submit

A deployed, in-progress style guide with all of the following working:

  • All CSS custom properties defined in :root
  • The typography section and the colour swatch section complete
  • At least two interactive components functional, even if unpolished

Submit to Canvas: the live URL, your repository URL, and a brief text-entry note (2–4 sentences) saying what is still remaining and where you expect trouble.

How this is graded

  • Deployed and on track (25) — live URL loads, tokens defined, both required sections complete, two components functional, remaining-work note is specific
  • Deployed with one requirement short (20) — for example one component instead of two
  • Deployed but early (15) — tokens present, sections incomplete
  • Repository progress only, nothing deployed (8) — deployment is the thing this checkpoint exists to de-risk
  • Not submitted (0)

If your live URL does not load, you have found exactly the problem this milestone is for. Post in Help & Questions before the deadline rather than submitting a broken link.
