Final Project Pitch and Planning Starter – Milestone 1

Due: End of Week 12
Points: 20
Category: Projects (Milestone 1 of 5)

Purpose

The first graded checkpoint for the Final Project. It is deliberately small. The goal is not finished planning — it is to make Week 13 a revision week instead of a cold start. Budget 20 to 45 minutes.

What to submit

Create projects/final-project/pitch.md containing the eight items listed in the brief's Milestone 1 section:

  1. One-sentence description — what it does and for whom
  2. Problem statement — 2–3 sentences on the specific problem and why this audience needs it
  3. Feature list — 3–5 bullets describing what a user can do
  4. API or data source — an example endpoint or a sample of the JSON
  5. Tech stack decisions — vanilla JS or Vue, which API, any other libraries
  6. Starter sketch — one rough sketch of the initial/empty state or the loaded state
  7. Data starter — one draft normalized object with 4–6 likely properties, plus a sentence on what you expect to store in localStorage
  8. API viability check — four bullets on CORS, rate limits/auth, attribution, and data reliability

Submit to Canvas: your repository URL, plus a direct link to pitch.md in the text entry.

How this is graded

  • All eight items, audience and data both concrete (20)
  • All eight, but the sketch or data starter is a placeholder (16)
  • Six or seven items (12)
  • A described idea with no sketch and no data work (8)
  • Not submitted (0)

Pitch feedback comes back within 48 hours. If the scope is too large or too small you will be asked to adjust before proceeding — so submit on time even if you are not confident in the idea. An early "narrow this" is worth far more than a polished pitch that arrives late.
